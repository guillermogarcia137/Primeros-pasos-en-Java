# Primeros pasos en Java

Mis apuntes y ejercicios de Programación de 1.º de DAM. Están organizados por temas para tener los ejemplos y las funciones a mano.

## Por dónde empezar

- [superEj.java](SuperEj/src/superej/superEj.java): menú con ejemplos, funciones y ejercicios de tablas y cadenas. Las chuletas rápidas están al final del archivo.
- [superEj2.java](SuperEj/src/superej/superEj2.java): otra versión de los apuntes, con submenú de cadenas.
- [Apuntes rápidos](SuperEj/apuntesRapidos.txt): consulta directa de tablas, cadenas y entrada con Scanner.
- [Ejercicios del aula virtual](Ejercicios%20aulavirtual/): enunciados y documentos separados por tema.

## Cómo ejecutarlo

1. Abre en NetBeans la carpeta del proyecto que quieras probar, por ejemplo `SuperEj` o `Cadenas2`.
2. Busca el archivo dentro de `src`.
3. Ejecuta la clase que tenga `main` e introduce los datos en la consola.

Usa la misma versión de Java para compilar y ejecutar. Cada carpeta de proyecto se puede abrir por separado. Hay ejercicios en proceso y varias versiones para comparar.
